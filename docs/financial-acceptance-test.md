# اختبار القبول المالي (قبل التسليم)

> كل الأرقام أدناه **ليست تقديرًا**. نفس هذا السيناريو مُنفَّذ آليًا على دوال قاعدة بياناتك الحقيقية (نسخة من هيكلها)، والأرقام محسوبة بنفس كود صفحة المحاسبة: `database/tests/acceptance-scenario.db.test.ts`.
> إذا ظهر على الشاشة رقم مختلف، فهناك خطأ يجب الإبلاغ عنه.
> أرقام صفحة المحاسبة بالدولار، وسعر الصرف في كل السيناريو **2,500 ج.س للدولار**.

## 0) التجهيز
1. خذ نسخة احتياطية (`docs/go-live-steps.md` الخطوة 1).
2. نفّذ `database/maintenance/reset_test_data.sql` في SQL Editor. يجب أن تظهر في النتيجة **حسابات المالك فقط**.
3. سجّل الدخول بالمالك، ثم:
   - الإعدادات ← **سعر الصرف 2500**.
   - الموظفين ← أضف **كاشير** و**خياط**.
   - الموردين ← أضف **«مورد الأقمشة»**.
   - المنتجات ← أضف منتجين:
     - **قميص** (قطعة) بسعر بيع **20$**.
     - **قماش** (متر) بسعر بيع **10$**.
     - معامل التحويل 1، والكمية صفر.

## 1) الأرصدة الافتتاحية (المحاسبة ← الأرصدة الافتتاحية)

| البند | القيمة |
|---|---|
| الخزينة جنيه | 1,000,000 |
| الخزينة دولار | 500 |
| البنك جنيه | 500,000 |
| البنك دولار | 1,000 |
| أصل: ماكينة خياطة (ماكينة، دولار) | 600 |
| دين: مورد الأقمشة | 300 |

- **المعاينة** يجب أن تُظهر أثرًا على رأس المال قدره **+2,400$**.
- **صفحة المحاسبة بعد التسجيل:**

| البطاقة | القيمة |
|---|---|
| الخزينة | 1,000,000 ج.س + 500$ |
| البنك | 500,000 ج.س + 1,000$ |
| إجمالي السيولة | **2,100$** |
| الأصول | **600$** |
| ديون الموردين | **300$** |
| رأس المال | **2,400$** |
| الإيرادات والأرباح | 0 |

- **القيود:** 6 قيود `JE-OPENBAL`. كل بند مدين ورأس المال دائن، ما عدا الدين: مدين رأس المال / دائن الموردين.
- **المشتريات:** يظهر أمر «دين افتتاحي» لمورد الأقمشة بقيمة 300$.

## 2) المخزون الافتتاحي (المخزون ← المخزون الافتتاحي)
- قميص: **10 × 8$**.
- قماش: **50 م × 4$**.

| بعدها | القيمة |
|---|---|
| المخزون | **280$** |
| رأس المال | **2,680$** |
| الإيراد | ما زال 0 |

قيد واحد `JE-OPEN`: مدين المخزون / دائن رأس المال، بقيمة 280$.

## 3) عمليتا بيع (الكاشير)
1. **قميصان + قميص هدية، نقدًا** ← الإجمالي **100,000 ج.س** (الهدية مجانًا).
2. **5 أمتار قماش، تحويل بنكي** ← **125,000 ج.س**.

**القيود:**

| العملية | القيود |
|---|---|
| البيع 1 | إيراد: الخزينة / المبيعات 100,000 ج.س (=40$) · تكلفة: COGS / المخزون 16$ · هدية: هدايا / المخزون 8$ |
| البيع 2 | إيراد: البنك / المبيعات 125,000 ج.س (=50$) · تكلفة: COGS / المخزون 20$ |

**صفحة المحاسبة:**

| البطاقة | القيمة |
|---|---|
| الخزينة جنيه | **1,100,000** |
| البنك جنيه | **625,000** |
| الإيرادات | **90$** |
| تكلفة المبيعات | **36$** |
| مجمل الربح | **54$** |
| المصروفات | **8$** (هدايا للعملاء) |
| صافي الربح | **46$** |
| المخزون | **236$** |

**المخزون:** قميص **7**، قماش **45**.

## 4) طلب تفصيل لعميل (من شاشة التفصيل)
**بيانات الطلب:**
- العميل: أحمد.
- المقاسات: الطول 150 سم، الكم 60 سم.
- القماش: من مخزون المحل، **3 أمتار**.
- السعر: **150,000 ج.س**، والعربون **75,000 نقدًا** (يجب أن يكون 50%).
- تكلفة الخياطة (أجر الخياط): **25,000 ج.س**.

| الخطوة | ما يجب أن تراه |
|---|---|
| 4أ. إنشاء الطلب | الخزينة جنيه **1,175,000** · التزامات العملاء (عرابين) **30$** · قماش **45** (لم يُخصم بعد) · الإيراد ما زال **90$** |
| 4ب. «بدء التفصيل» | قماش **42** (خُصم مرة واحدة) · المخزون **224$** · تحت التشغيل **12$** · قيد: تحت التشغيل / المخزون 12$ |
| 4ج. «جاهز» ثم «تسليم» مع تحصيل الباقي 75,000 نقدًا | الخزينة جنيه **1,250,000** · العرابين **0** · تحت التشغيل **0** · مستحقات الخياطين **10$** · الإيرادات **150$** · تكلفة المبيعات **58$** · مجمل الربح **92$** · صافي الربح **84$** |
| 4د. دفع للخياط 25,000 نقدًا | الخزينة جنيه **1,225,000** · مستحقات الخياطين **0** · صافي الربح **84$** (لا يتغير) |

**قيود التسليم:**
- أجر الخياط: تحت التشغيل / مستحقات الخياطين 10$.
- التكلفة: COGS / تحت التشغيل **22$** (قماش 12 + أجر 10).
- إيراد العربون: العرابين / المبيعات 30$.
- إيراد الباقي: الخزينة / المبيعات 30$.
- **ربح الطلب = 60 − 22 = 38$.**

## 5) مصروف: فاتورة كهرباء 20,000 ج.س نقدًا (المحاسبة ← قيد جديد ← مصروف)
## 6) سداد 100$ نقدًا لمورد الأقمشة (المشتريات ← الدين الافتتاحي ← دفعة)

## النتيجة النهائية في صفحة المحاسبة

| البطاقة | القيمة |
|---|---|
| الخزينة | **1,205,000 ج.س + 400$** |
| البنك | **625,000 ج.س + 1,000$** |
| إجمالي السيولة | **2,132$** |
| المخزون | **224$** (قميص 7، قماش 42) |
| الأصول | **600$** |
| ديون الموردين | **200$** |
| رأس المال | **2,680$** |
| الإيرادات | **150$** (= 375,000 ج.س) |
| تكلفة المبيعات | **58$** |
| مجمل الربح | **92$** |
| المصروفات | **16$** (كهرباء 8 + هدايا 8) |
| **صافي الربح** | **76$** |

**اختبار التوازن** (يجب أن يتحقق دائمًا):
- السيولة 2,132 + الأصول 600 + المخزون 224 = **2,956**.
- الديون 200 + رأس المال 2,680 + الربح 76 = **2,956** ✔

**القيود اليومية:** المجموع **21 قيدًا** (6 افتتاحية + 1 مخزون + 5 بيع + 6 تفصيل + 1 دفع خياط + 1 مصروف + 1 دفعة مورد).

**لوحة التحكم والتقارير (لليوم):** تحسب أرقامها بطريقة مختلفة (من الطلبات والفواتير)، فلم أُثبت أرقامها آليًا. **يجب أن تتطابق** مع صفحة المحاسبة: مبيعات **375,000 ج.س (150$)**، ومخزون قميص 7 وقماش 42. أي اختلاف أرسله لي.

## سؤال الأصول: هل تُسحب من رأس المال؟
**لا.** الأصل في الرصيد الافتتاحي **يزيد** رأس المال ولا يسحب منه، ولا يخرج أي مال من الخزينة.

**بلغة المالك:** رأس المال = كل ما وضعته في المتجر يوم البداية. فلوس + بضاعة + أجهزة، ناقص ما عليك للموردين.

في هذا السيناريو:

| البند | القيمة |
|---|---|
| فلوس | 2,100$ |
| ماكينة | + 600$ |
| دين للمورد | − 300$ |
| **= رأس المال من الأرصدة الافتتاحية** | **2,400$** |
| بضاعة | + 280$ |
| **= رأس المال الكلي** | **2,680$** |

الماكينة تبقى ظاهرة في بطاقة «الأصول» بقيمتها. لا تُحسب مصروفًا ولا تُنقص الربح.

(شراء أصل **جديد** بعد بدء التشغيل من صفحة الأصول شيء مختلف: يخرج ثمنه من الخزينة أو البنك، ولا يتغير رأس المال.)
