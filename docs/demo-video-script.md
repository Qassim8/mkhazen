# نص تصوير فيديو العرض للعميل

> 8 مقاطع قصيرة (2–4 دقائق لكل مقطع). كل مقطع: **ماذا أفتح ← ماذا أُدخل ← أي رقم أُشير إليه ← جملة واحدة أقولها**.
> الأرقام مطابقة لـ [financial-acceptance-test.md](financial-acceptance-test.md). اطبع هذه الورقة وضعها بجانبك أثناء التصوير.

## قبل التصوير (بدون كاميرا)
- [ ] نسخة احتياطية، ثم `reset_test_data.sql` (يبقى المالك فقط).
- [ ] سجّل الدخول بالمالك. جهّز مسبقًا (لا تصوّر هذا): سعر الصرف **2500**، كاشير، خياط، «مورد الأقمشة»، والمنتجان **قميص 20$** و**قماش 10$**.
- [ ] تكبير المتصفح 110–125% حتى تُقرأ الأرقام، وإخفاء الإشعارات، وإغلاق التبويبات الأخرى.
- [ ] افتح تبويبين ثابتين: **صفحة المحاسبة** و**صفحة المخزون**. بعد كل خطوة ارجع إليهما وحدّث الصفحة.
- [ ] برنامج تسجيل الشاشة: OBS (مجاني)، أو Windows + Alt + R (Xbox Game Bar).

---

## المقطع 1 — الفكرة (دقيقة، بدون إدخال)
افتح صفحة المحاسبة وهي فارغة.
**قل:** «نبدأ من الصفر. سنُدخل وضع المحل يوم البداية، ثم نبيع، ونفصّل، وندفع مصروفًا، ونتأكد أن كل رقم صحيح».

## المقطع 2 — الأرصدة الافتتاحية
المحاسبة ← الأرصدة الافتتاحية:
- الخزينة: 1,000,000 ج و500$.
- البنك: 500,000 ج و1,000$.
- أصل: ماكينة خياطة 600$.
- دين: مورد الأقمشة 300$.

اضغط **معاينة**، وأشِر إلى **+2,400$**، ثم سجّل.
**أشِر في المحاسبة إلى:** السيولة **2,100** · الأصول **600** · ديون الموردين **300** · رأس المال **2,400**.
**قل:** «رأس المال = فلوس + ماكينة − دين».

## المقطع 3 — المخزون الافتتاحي
المخزون ← المخزون الافتتاحي: قميص 10 × 8$، قماش 50 × 4$.
**أشِر إلى:** المخزون **280** · رأس المال **2,680** · الإيراد ما زال **0**.
**قل:** «البضاعة تزيد رأس المال ولا تُحسب ربحًا».

## المقطع 4 — البيع (سجّل الدخول بحساب الكاشير)
- بيع 1: قميصان + قميص **هدية**، نقدًا (100,000 ج).
- بيع 2: 5 م قماش، تحويل بنكي (125,000 ج).

ارجع للمالك وأشِر إلى: الإيراد **90** · التكلفة **36** · الهدايا **8** · صافي الربح **46** · المخزون: قميص **7**، قماش **45**.
**قل:** «الهدية لم تدخل الفاتورة، لكن تكلفتها ظهرت كمصروف».

## المقطع 5 — طلب التفصيل
1. **إنشاء الطلب:**
   - العميل: أحمد.
   - المقاسات: الطول 150 سم، الكم 60 سم.
   - القماش: 3 م من المحل.
   - السعر 150,000، والعربون 75,000 نقدًا.
   - أجر الخياط 25,000.

   ← أشِر إلى: العرابين **30$** · القماش ما زال **45**.
2. **بدء التفصيل** ← القماش **42**، وتحت التشغيل **12$**.
3. **جاهز** ثم **تسليم** وتحصيل 75,000 ← الإيراد **150** · التكلفة **58** · صافي الربح **84**.
4. **دفع للخياط** 25,000 ← مستحقات الخياطين **0**.

**قل:** «القماش خُصم مرة واحدة، والربح ظهر فقط عند التسليم».

## المقطع 6 — مصروف وسداد مورد
- قيد جديد ← مصروف ← كهرباء 20,000 ج نقدًا.
- المشتريات ← الدين الافتتاحي ← دفعة 100$.

**أشِر إلى:** المصروفات **16** · ديون الموردين **200**.

## المقطع 7 — النتيجة النهائية (أهم مقطع)
اعرض صفحة المحاسبة كاملة ببطء:
- الخزينة **1,205,000 ج + 400$**.
- البنك **625,000 ج + 1,000$**.
- السيولة **2,132**.
- المخزون **224**.
- الأصول **600**.
- ديون الموردين **200**.
- رأس المال **2,680**.
- الإيراد **150**.
- **صافي الربح 76**.

**قل الجملة الذهبية:** «ما نملكه 2,132 + 600 + 224 = **2,956**، يساوي ما علينا ورأس مالنا وربحنا 200 + 2,680 + 76 = **2,956**. الحسابات متوازنة».

## المقطع 8 — جولة سريعة (اختياري)
- القيود اليومية: 21 قيدًا.
- لوحة التحكم: المبيعات **375,000 ج**.
- التقارير.
- صفحة الأصول: الماكينة بعلامة «رصيد افتتاحي».

## إذا أخطأت أثناء التصوير
- **خطأ إدخال قبل الحفظ:** صحّحه وأكمل، أو أعد المقطع.
- **حفظت رقمًا خاطئًا:** أوقف، ونفّذ `reset_test_data.sql`، ثم جهّز الأساسيات وابدأ من المقطع 2. لا تحاول التصحيح أمام الكاميرا.
- **ظهر رقم لا يطابق الورقة:** خذ لقطة شاشة وأرسلها لي قبل إكمال التصوير.

## بعد التصوير
نفّذ `reset_test_data.sql` مرة أخيرة، ثم أدخل **الأرصدة الحقيقية** للمحل.
